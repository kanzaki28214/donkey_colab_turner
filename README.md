# Donkey_Colab_Turner
donkeycar5.1.0に対応したハイパーパラーメータチューニング用プログラムです
環境はGoogleColabを想定しています

tflite、h5、kerasの３つのモデルが学習されます

# 使い方
本データをGoogleDriveのローカルにコピーします
DonkeyTrain_base.ipynbを開いてランタイムに接続します
    ランタイムタブの「ランタイムのタイプを変更」でT4を選択します（T4＜L4＜A100の処理性能です）
    donkeycarなら教師データの量にもよりますが、画像1万枚でもL4で十分な速度です

準備1のドライブのマウントからスタートしてDonkeycar5.1.0のインストール、Colabに合ったTensorflowのインストールなどを進めてください

準備7まで終わったら学習の準備完了です

# セットアップと学習

Donkeycarの走行データをzipに圧縮して同じくGoogleDriveのローカルにコピーします

準備1.1の再読み込みを行い、そのzipファイルをmycarにドラッグアンドドロップでコピーします

1.教師データの解凍、移動
    unzipコマンドのパスを合わせて解凍し、下のcpコマンドのパスも合わせてmycar内に教師データを移動します

2.学習開始
    このプログラムは２個の学習方法が準備されてます
    donkeycar標準の学習方式とハイパーパラメータチューニング機能のついた学習方式です

どちらも混合精度トレーニングが行われてます

標準の方はmyconfigの設定がそのまま使われる学習（のはず）

ハイパーパラメータチューニングはlossの値を見ながら最適なパラメータを探すものです
tryのあとの数字が試行回数です。（何回まで最適なパラメータを探すか）
詳しい内容はmanage.pyの上の方に書かれてます

# その他
